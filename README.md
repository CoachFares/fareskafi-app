# خريطة الوعي بالعلاقة — البنية الأساسية (الخطوة ١)

## وش تم بناؤه الآن

هذا هيكل المشروع الكامل، مقسّم بالضبط بالطريقة اللي اتفقنا عليها:

| الملف | وظيفته |
|---|---|
| `supabase/schema.sql` | تصميم قاعدة البيانات — أربع جداول: العملاء، الرحلات، الإجابات، التقارير |
| `lib/supabase.ts` | نقطة الاتصال الوحيدة بقاعدة البيانات |
| `lib/reportEngine.ts` | منطق بناء التقرير — منفصل تمامًا عن كل شيء آخر |
| `app/api/gumroad-webhook/` | يستقبل إشعار البيع من Gumroad، وينشئ وصول العميل |
| `app/api/save-answer/` | يحفظ إجابة كل محطة أول بأول |
| `app/api/generate-report/` | يبني التقرير الأساسي بعد آخر محطة |
| `app/api/ai-analysis/` | **خيار "التحليل الأعمق بالذكاء الاصطناعي"** — آمن، يشتغل على السيرفر فقط |

## خطوتك الوحيدة الآن

إنشاء حساب مجاني على [supabase.com](https://supabase.com)، وإنشاء مشروع جديد (اسمه مثلًا "fareskafi"). بعدها ادخل على SQL Editor داخل المشروع، وألصق فيه محتوى ملف `supabase/schema.sql` واضغط Run. هذا كل المطلوب منك بهذي الخطوة — ياخذ ٥ دقائق.

بعدها ترسل لي من نفس الصفحة (Settings → API) قيمتين: `Project URL` و`service_role key` — أحطهم أنا في مكانهم الصحيح، ما تحتاج تفهم وش وظيفتهم بالضبط.

## الخطوة الجاية

بعد ما تتأكد قاعدة البيانات شغّالة، ننتقل للخطوة ٢: ربط Gumroad الفعلي وإنشاء رابط الوصول التلقائي — وأوريك يشتغل بعملية شراء تجريبية حقيقية قبل ما نكمل.
